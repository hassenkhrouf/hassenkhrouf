## Featured projects

### Job Board
SEO-first job platform with public search, an admin dashboard, and AI-assisted job importing.

- Next.js + PostgreSQL + Prisma
- Authentication, full CRUD, and admin workflows
- JSON-LD structured data, sitemap, and canonical URLs
- Dockerized local database

[Live demo](https://job-board-delta-six.vercel.app) · [Source](https://github.com/hassenkhrouf/job-board)

### Banking System
Full-stack banking application with authentication and account management.

- Angular 21 frontend, Spring Boot 3.5 backend, PostgreSQL
- JWT authentication and protected routes
- Docker Compose setup, deployed frontend and API
- MIT licensed

[Live demo](https://banking-system-weld.vercel.app/) · [Source](https://github.com/hassenkhrouf/banking-system)

### React Admin Dashboard
Responsive admin dashboard for managing application data and business workflows.

- React + Vite, Material UI, Nivo charts
- Data tables, calendar, and reusable components
- Light and dark themes

[Live demo](https://react-admin-dashboard-seven-psi.vercel.app) · [Source](https://github.com/hassenkhrouf/React-Admin-Dashboard)

### Kids Book Explorer
Full-stack reading platform for children, split into two repositories.

- Angular standalone components frontend
- Spring Boot 3 REST API with clean architecture
- MySQL persistence and JPA

[Frontend](https://github.com/hassenkhrouf/kids-book-explorer-frontend) · [Backend](https://github.com/hassenkhrouf/Kids-Book-Explorer-Backend)

### Flutter Task App
Small task manager built to explore cross-platform mobile development.

- Add, complete, and delete tasks
- Flutter with local state management
- Web build deployed on Vercel

[Live demo](https://flutter-task-app.vercel.app) · [Source](https://github.com/hassenkhrouf/flutter-task-app)
